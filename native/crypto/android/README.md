# Android crypto package

`build-package.sh` cross-compiles the existing UniFFI crypto engine for arm64, armv7 and x86_64, and generates matching Kotlin bindings. Set `VOICS_ANDROID_ABIS=x86_64` for the isolated emulator build. Run it in an isolated build job with preinstalled Rust targets and Android NDK; set `CARGO_TARGET_DIR` and `CARGO_HOME` to job-local paths. Pass a new output directory and package that directory as a short-lived build artifact.

The generated binding and every `.so` must come from the same commit. Copy `Generated/` and `jniLibs/` from the package into `apps/mobile/modules/voics-crypto/android/` in an isolated build checkout before Expo prebuild. Gradle uses the Android JNA AAR and the full Keystore-backed Expo bridge only when those directories exist; otherwise it compiles a stub that reports unavailable. The generated binding, native libraries, JNA integration, MLS interoperability and device route still require a clean Android build and verification. A missing package leaves private delivery unavailable; it never sends plaintext instead.
