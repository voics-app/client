# Changelog

## Unreleased

- Calls with end-to-end encryption work on the iPhone (client#297). Desktop and phone now share one media frame format (DAVE protocol version 2, the LiveKit cryptor layout) and the old format is gone: the voice server announces version 2 only, and an app that sees another version leaves the call with a clear message. This release must ship together with the voice server change and the new mobile build, because desktops on the old format and the new frames cannot decrypt each other. Mobile: the WebRTC package is now `@livekit/react-native-webrtc` 150.1.0, the DAVE session runs on the Rust engine, the native frame cryptor is attached and confirmed before any media can flow, remote tracks stay muted until protected, and the Privacy page has the Encrypt all my calls switch. H.264 video is refused in encrypted calls. Internal: `DaveSession` moved into core, with `EpochKeyBook` and `domain/frameFormat.ts` (the new layout; the frame key label is now `voics-voice-frame-key`).
- New messages in a DM or group show that conversation's avatar above the servers in the sidebar, with the number of new messages, on desktop and mobile.
### Fixed

- You stay signed in: an expired access token on the gateway now refreshes the session instead of deleting the login, and a failed refresh while offline keeps it too.

- Mobile app: parity polish (client#280). The magnifier in the column header opens a quick switcher over channels, conversations, servers and screens (prefixes @ # ! *, recent and unread first). Typing / in a chat lists slash commands; a command opens a sheet for its options, and bots' buttons, select menus and forms work in messages. Tablets (iPad, `supportsTablet` on) keep the rail and channel list beside the chat. The user panel shows the presence dot on your avatar and opens a status sheet (status, custom status, Edit profile, Settings). A collapsed category keeps the open channel, mentions, unread text channels and occupied voice channels visible, as on desktop. Appearance says that a theme or accent change needs a restart. Stickers are not built (desktop has none either); polls and voice messages wait for an owner decision.
- Internal: the status choices and the status shown on your own avatar (`selfPresence`), the quick switcher's channel items (`quickSwitcher`), the people, role and channel choices for command options and selects (`entityChoices`) and the form, select and button rules of message components (`slashCommand`) moved into `@discordy/core`; desktop uses them. No change in desktop behaviour.
- Mobile app: forums, forwarding, drafts and offline messages (client#279). A forum channel shows its posts and, with the permission to start threads, New post. Forward is in the message menu, with a picker of chats and channels and an optional comment (encrypted chats cannot receive forwards), and forwarded messages show what was forwarded. Unsent text is kept per chat as a draft. The newest messages of recent chats are saved on the phone, so a chat opens at once and still opens offline; they are removed when you sign out.
- Internal: forwarding (`forwardCommands`: `forwardMessage`, `permissionsInChannel`) moved into `@discordy/core`; desktop uses it. No change in desktop behaviour.
- Mobile app: servers and groups (client#279). The + in the server rail offers Create my own server (empty, from a template or from a template link), Join a server and Discover servers (search, categories, tags, Join). Long-press a server or folder to move it, make or rename a folder, add or remove a server from a folder, or ungroup. A group DM has settings (name, icon, members, leave). Messages with an invite link to this server show an invite card with Join, and tapping an invite link opens the join sheet inside the app. Search results can be sorted by newest, oldest or most relevant.
- Mobile app: server administration (client#279). Server settings gains Emoji (upload, rename, delete), Bans (search, Unban) and Audit log (filter by action and moderator, older entries). A member's sheet in Members, or Manage member in their profile, offers roles, nickname, timeout, kick and ban (with message history and a reason) by the same rules as desktop, and Members can show only timed-out people. Roles and Channels can be reordered with up and down buttons, and each channel has a settings page (topic, slowmode, age restriction, voice limits, permissions for roles and members, delete). The server menu has Mark as read, Mute server, Notification settings and, for the owner, Delete server after typing its name.
- Internal: marking read, saving the server rail, leaving and deleting a server (`guildCommands`), sending channel moves (`channelOrderCommands`) and the audit log wording (`auditActions`) moved into `@discordy/core`; desktop uses them. No change in desktop behaviour.
- Mobile app: settings and account (client#279). The user panel opens Settings: a search field over every page and row, then My account (username, email, password, two-factor setup with backup codes, disable and delete, each asking for the password as desktop does, and Log out after a confirmation), Profile (avatar, banner, display name, About me, colour, status and custom status), Privacy and delivery (default mode, per-chat overrides, blocked people with Unblock), Devices and sessions (log out one or all other devices), Appearance (Dark, OLED or Light, accent, text size), Accessibility, Notifications and Chat. A new theme or accent shows from the next start of the app. Block User is in the message menu, after a confirmation. There is no report function because the api has no report endpoint yet. Theme, accent, text size, reduce motion, role colours and the other synced preferences now follow your account on mobile too.
- Internal: the settings search ranking (`settingsSearch`) and the custom status builder (`buildCustomStatus`) moved into `@discordy/core`; the desktop settings search and custom status use them. No change in desktop behaviour.
- Mobile app: the Friends tabs no longer run Add friend off the right edge; Add friend is a pinned button at the end of the row and Online, All, Pending and Blocked scroll beside it on narrow screens.
- Mobile app: find and navigate (client#278). Tapping the chat title opens channel details (name, topic, Search, Pinned messages, Threads, Members, Copy link; in a 1:1 DM it opens the profile, in a group the people in it). Pinned messages open from details and from the link in a pin notice, with Jump (back to the chat at that message) and Unpin for those who may. The profile sheet now has the banner colour, status, Message, Add friend or Accept or Remove friend, Block or Unblock (with confirmation), your private note, mutual servers and mutual friends. Create Thread is in the message menu (with Create Public Threads), a thread chip sits under the message that started one, thread notices link to it, a thread opens as a chat (locked threads close the composer unless you manage threads) and channel details lists the threads the app knows about. Search (from details or the header menu) takes words and the desktop filters (`from:`, `in:`, `has:`, `mentions:`, `before:`, `after:`, `during:`, `pinned:`) with suggestions, searches the whole server (or the direct message), and shows Messages, Media, Files and Links tabs. A + button at the end of the server rail joins a server from an invite link or code (preview first), and a voice channel has an Open text chat button. Bottom sheets with a text field lift above the keyboard.
- Internal: the message search service (now with a store-free `page()`), the search name candidates (`searchCandidates`) and the thread rules (`threads`) moved into `@discordy/core`; desktop uses them. No change in desktop behaviour.
- Mobile app: notifications and direct messages (client#278). The bell opens the mentions inbox as on desktop: mentions and replies grouped by server, tap to open the chat at that message (the chat loads the messages around it and a Jump to latest button brings you back), a check marks one read and Mark all read clears the list. While you are elsewhere in the app, a new message that your notification settings allow shows a banner at the top (tap to open it, it goes away by itself; not for your own messages, the chat on screen, muted chats or Do Not Disturb). The Direct messages column has Friends (with the number of requests) and New message rows, pinned conversations at the top (up to five), and a long-press menu with Mark as read, Pin, Profile, Mute, Close DM and Leave group. New message picks one person for a DM or several for a group DM. Friends has Online, All, Pending (accept, decline, cancel), Blocked (unblock) and Add friend by username, and tapping a friend offers Message, Profile, Remove friend and Block.
- Internal: the rule that decides whether a message deserves a sound, notification or banner (`incomingAlert`, `alertBody`) and the DM commands (pin, close, open, leave: `dmCommands`) moved into `@discordy/core`; the desktop toast and DM pins use them. No change in desktop behaviour.
- Mobile app: emoji, menu, gestures. An emoji picker (search, recently used, the server's custom emoji, categories) for the composer and for reactions, with a + chip under messages and a sheet listing who reacted (long-press a reaction). The message menu adds Copy Message Link, Mark Unread and, with Manage Messages, Pin. Swipe a message left to reply, with haptics (off with Reduce Motion). The chat header's ... menu has Mark as read, Mute, Notification settings and Invite people.
- Mobile app: unread and attachments. A chat opens at the first unread message with a New divider and a count bar (Mark as read), and a Jump to latest button appears after scrolling up. The + button offers the photo library, the camera and files with previews and a remove button; images and videos show in a grid with a full-screen viewer, audio and files as rows, and an unsent message shows its upload progress with Cancel. The Select Text sheet is only as tall as the message.
- Mobile app: voice in a development build (EAS profiles `development` and `preview`, dev client, react-native-webrtc). Join and leave voice channels, mute, deafen, see who speaks, switch between speaker and earpiece, start a DM call and accept or decline an incoming one. Expo Go keeps working and shows the "not in this test version" notice. Video, encrypted calls, CallKit and PushKit are not included.
- Internal: the voice session, the call controller, the WebRTC and media ports and the TURN credentials moved into `@discordy/core`; the desktop builds on them (camera, screen share and devices stay desktop). No change in desktop behaviour.

- Mobile app: chat. Long-pressing a message opens a real bottom sheet (the dark backdrop now fades in by itself instead of sliding up with the sheet, and it no longer shows as a black layer over the keyboard); the same sheet is used for the profile and the server menus. The message menu has Copy Text and Select Text. Messages render markdown (bold, italic, code, code blocks, quotes, lists, headings, spoilers), links (in an in-app browser), mentions, custom emoji, role-coloured names and system messages, and replies show the original message above. The composer's + button now lines up with the placeholder.
- Mobile app: servers. The channel list shows voice, stage, announcement and forum channels with the desktop icons, the people in each voice channel, and the lock on ephemeral channels. A voice channel opens a screen with who is in it and a note that voice is not in this test version yet; ephemeral, peer-to-peer and forum channels open on a plain message. The people icon in a server channel's header opens the member list (grouped by role, online and offline, with status and search), and tapping a person shows their profile with a Message button. The server name opens a menu with Invite people, Server settings (only when you may change the server, its roles or its channels) and Leave server. Server settings has Overview (name, icon), Roles, Members (kick, ban), Invites (create, copy, revoke) and Channels (create, rename, delete), each with the desktop's permission checks and a confirmation before anything destructive.
- Internal: the channel kind rules (`channelIcon`) and the server settings page and menu permission rules (`serverSettings`) moved into `@discordy/core`; the desktop imports them. No change in desktop behaviour.
- Desktop: the first start after the rename carries your local data over from the old Discordy folder (settings, saved session, end-to-end encryption keys and databases, and the app's stored preferences). It only runs when the new folder holds no data yet, copies and never changes or deletes the old folder, and is retried on the next start if it was interrupted. On Windows the encrypted files stay readable; on macOS and Linux the OS secret store is keyed by app name, so you may need to sign in again.
- Mobile app: sign in (with the two-factor step and sign out), a live gateway connection that resumes after the app returns from the background, and the Servers tab with your servers and their text channels. Tokens are kept in the iOS Keychain (Android Keystore). Tapping a text channel opens its messages: history that loads older messages as you scroll, live updates, sending, replying, editing and deleting your own messages and adding or removing reactions, with send failures shown and Retry. Edit and delete only appear where you may use them. The DMs tab lists your direct and group conversations, newest first, and opens them in the same message screen (encrypted ones show the private-delivery notice); tapping an author or Profile in a 1:1 DM shows their avatar, names, About me and Friends since; the You tab shows your account, a Show reactions switch (this device only) and Sign out. Attachments follow; nothing is published to an app store yet.
- Internal: the gateway client has `resumeNow()` (replace the socket at once and resume the session) and the failed-command text `errorMessage` moved into `@discordy/core`. No change in desktop behaviour.

- Profiles: click an avatar to see it full size (the image viewer, with zoom), a friend's profile shows Friends since, and About me can be up to 300 characters (was 190; the api limit follows in a separate change).
- Screen shares zoom and pan: scroll or pinch to zoom toward the pointer (up to 8x), drag to pan, double-click or the zoom badge to reset.
- Messages with more than four images show a compact grid of four with a "+N" on the last tile, and swiping left or right in the image viewer turns to the next or previous image.
- Internal: fixed a flaky P2P attachments test; it stopped waiting for the link after a fixed number of ticks while the files were still being encrypted. No change in behaviour.
- Moderation: Duplicate role (role list context menu and role settings), Settings, Overview, Safety has Only administrators can prune members, Members has Prune members (pick 1 to 30 days, see how many would be removed, then confirm), and Mod View opens from a ban or an audit log entry to show a user who is no longer in the server with their ban reason and moderation history. Needs api#112 (prune) and the api#101 changes.
- Group DMs can have up to 25 members (was 10); the new-group dialog follows. Needs the api change that raises the cap (api#100); an api configured with a lower `GROUP_DM_MAX_PARTICIPANTS` will refuse the extra members with an error.
- Internal: the domain and application layers no longer touch `window`, `document` or `localStorage`; persistence goes through a storage port, a first step towards sharing the core with the mobile app. No change in behaviour.
- Internal: the mobile app skeleton depends on `@discordy/core` (the sign-in screen shows its delivery-mode copy with the installed brand); Metro and Jest resolve the workspace package.
- Internal: the application ports and 20 zustand stores (everything except the voice, session, update and transfer stores) moved into `@discordy/core` (`src/application`), which now depends on zustand. No change in behaviour.
- Internal: the product identity the domain rules read (name, deep-link scheme, hosts) is now an installed `BrandConfig` (`@discordy/core/domain/brandConfig`) instead of an import of the desktop brand module, so the six brand-aware rules (sessions, channel links, delivery modes, invites, link trust, templates) moved into `@discordy/core`. No change in behaviour.
- Internal: the domain rules and protocol contracts moved into the new `packages/core` workspace package (`@discordy/core`), which the desktop imports; the mobile app will share it.
- The composer has a timestamp picker: type @time or press the clock button, choose a date, time and format (short or long time, short or long date, date and time, relative), and it inserts a timestamp that every reader sees in their own time zone, with the full date on hover.
- Settings, Voice and Video has Confirm before calling (on by default, this device only): starting a voice or video call that nobody is in yet asks "Start a voice call with X?" before it rings.
- Messages render GitHub-style pipe tables: a header row, per-column alignment (`:--`, `:-:`, `--:`) and horizontal scrolling when wide; limited to 12 columns and 50 rows.
- Settings, Devices now lists where you are logged in (client, OS, approximate location, last active) with a Log out per device and Log out all known devices; revoked devices are signed out right away. Needs the api and gateway session revocation.
- Fixed components at the bottom of the window lagging and leaving a trail while resizing on Windows: the voice dock is opaque, and blur and transitions are suspended during a resize.

## 0.2.0

Calls, privacy and servers catch up with Discord.

- Invite links: `https://discordy.voics.nl/invite/<code>` opens the app (also on cold start and after sign-in) and joins the server after a confirmation.
- Calls: incoming ringing with a selectable ringtone and volume, ringback for the caller, leaving the call when the app closes, fullscreen video tiles, the call view opens from the channel list.
- Video: camera and screen share are separate streams; quality presets up to 4K for both, plus Source for the camera.
- Text chat beside voice channels (on by default, switchable per channel).
- Members: roles grouped in the member list, role editor and right-click menu with moderation and server nicknames.
- Ephemeral and P2P messages reach the other side (MLS welcome ordering, non-trickle ICE).
- Animated server icons and avatars; friends appear in the New DM picker immediately.

## 0.1.0

Initial release: Electron shell, design system, auth, servers, messaging, three delivery modes, voice, video and screen share.

- Single-source branding: the product name and identity live in `apps/desktop/brand.json`; the installer is configured by `electron-builder.config.cjs`.
- The Local connection profile now defaults to `127.0.0.1:18000` (API, gateway, `/cdn`).
- Native crypto module builds without OpenSSL or Perl.
- Slash commands, attachments, TURN support and voice engine fixes.
